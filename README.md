# CSSGradient - CSS Gradient Generator

A beautiful, dreamy purple-themed CSS gradient generator with multi-language support.

🌐 **Live Demo**: https://kanshaowz.github.io/cssgradient

## Features

- ✨ **Linear & Radial Gradients** - Create both types of gradients with ease
- 🎨 **Color Stop Management** - Add, remove, and customize color stops
- 📐 **Angle Control** - Precise angle adjustment for linear gradients
- 🎯 **Preset Gradients** - 12 beautiful preset gradients to get started
- 📋 **CSS Code Copy** - One-click copy to clipboard
- 🌍 **5 Languages** - English, 中文, Español, 日本語, 한국어
- 💜 **Dreamy Design** - Purple gradient aesthetic with glassmorphism effects

## Design Philosophy

- **Dreamy Purple Theme** - Deep purples, pinks, and cyans
- **Glassmorphism UI** - Translucent panels with subtle borders
- **Animated Stars** - Twinkling background for magical feel
- **Responsive Layout** - Works beautifully on all devices

## Technologies

- Pure HTML5, CSS3, JavaScript
- No dependencies
- CSS Custom Properties for theming
- CSS Animations for effects
